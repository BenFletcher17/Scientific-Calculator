# Scientific Calculator

A desktop scientific calculator built with Python and CustomTkinter.

## Features

- Basic arithmetic
- Addition, subtraction, multiplication and division
- Brackets
- Decimal calculations
- Sine, cosine and tangent
- Clear button
- Backspace button
- Graphical user interface
- Custom button colours and layout

## Technologies

- Python
- CustomTkinter
- Math
